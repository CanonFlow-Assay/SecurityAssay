# SecurityAssay M0

Read `/home/arun/Developer/AGENTS.md` in every session. This new undertaking is
authorized through local Forgejo draft review only. Never read credential files,
merge PRs, write GitHub, publish packages or imply human approval.

Implement in C# with exact .NET 11 RC1 from global.json, preview language,
nullable and warnings-as-errors. Native unions express closed domain outcomes.
Keep pure evidence/policy decisions separate from scanner/process/file adapters.
No Python source or interpreter dependency. No sub-agent work is authorized.

Read README.md and docs/M0-CONTRACT.md before implementation. SecurityAssay adapts
approved existing tools; it is not a replacement scanner. Pin binaries, approved
configuration, database bytes/version, ASVS catalog and policy. Authoritative M0
evaluations run without network and accept only declared source/lock/config files.
No shell execution from manifests, no ambient scanner configuration, no host
home/credentials/Docker socket mounted in scanner containers. Verify inputs,
tool images and databases before/after execution. Missing, unsupported, stale,
interrupted, malformed or unknown evidence must never become Pass.

Normalize findings into SARIF and a deterministic hashed receipt with an SBOM.
Preserve raw evidence separately in ignored artifacts; redact secrets at the
scanner boundary. Every finding needs a valid versioned ASVS requirement mapping;
mapping is related evidence, not proof the whole ASVS requirement is verified.
Top 10:2025 is only a risk map. Explicitly list unassessed controls and limitations.
No secure/OWASP-certified claims. No automatic waiver, equivalence or suppression.

Use real scanner runs and negative controls: secrets, vulnerable lock, source/
binary/database/config tampering, missing tool/DB, stale DB, unrecognized finding,
invalid scope, undeclared files, malformed reports, timeout and determinism.
Source-bound qualification needs a clean committed candidate. Never relabel
historical evidence or synthetic adapters as real scans.
